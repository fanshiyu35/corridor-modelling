Model Manager

The platform for regional travel-demand modelling, forecasting and project evaluation.

Model Manager supports the full workflow of regional travel-demand modelling: network editing, trip generation and distribution, mode choice, assignment, and the scenario and project evaluation families used by agencies and consultants. Performance improvements to the network skim engine and updated base-year network bundles ship with every release.

Project Evaluation family

The Project Evaluation modules turn modelled scenarios into decisions. The family includes project screening, scenario comparison and benefit estimation, and — since version 9.7 — the Ranking Stability module.

Ranking Stability module (MTRS)

The Ranking Stability module implements the Multivariate Transport Ranking Stability (MTRS) test, licensed from the University of California, Irvine (Agreement UCI-OTA-2025-001, 15 January 2025). The MTRS test reports, for any set of ranked transport scenarios or projects, how firmly the ranking holds across the six recognized sources of uncertainty: model structure, parameters, data vintage, policy mapping, weights, and metropolitan area structure.

  • Implements the procedure defined in Research Report No. 212, National Transport Research Programme (May 2024).
  • Outputs conform to the reporting structure of SP-41: Reporting on the Stability of Scenario Rankings (September 2024).
  • Available to customers in the Project Evaluation module; enablement is governed by the terms of each customer's licence agreement.
  • Stability verdicts are exported as standard report tables (STABLE / REVERSAL / NON-TRANSFERABLE) together with the underlying variance decomposition.

The module was introduced in Model Manager version 9.7 (March 2025).
